# Python-Data-Analysis-Numpy-and-Pandas
Python assignment covering data analysis using NumPy and Pandas, including arrays, Series, DataFrames, indexing, slicing and data manipulation.

In this assignment, I practised using NumPy and Pandas to create, explore and manipulate data.

## Topics Covered

### 1. NumPy
- Creating 1D and 2D arrays
- Array properties and operations
- Celsius to Fahrenheit conversion
- Maximum, minimum and mean
- Array indexing and slicing

### 2. Pandas Series
- Creating Series
- Indexing and slicing
- Using loc and iloc
- Boolean masking
- Modifying and deleting values
- Calculating CGPA

### 3. Pandas DataFrame
- Creating DataFrames
- Data exploration
- Filtering data
- Value counts and unique values
- Grouping and calculating averages
- Adding, modifying and deleting columns and rows

## Tools Used
- Python
- Jupyter Notebook

## Purpose
The purpose of this assignment is to improve my understanding of Python data analysis using NumPy and Pandas.
